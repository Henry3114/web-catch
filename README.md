# 网页采集工作台（独立试用版 0.3.0）

这是一个单独的新项目。它不引用 BOSS 专用扩展的运行环境，不覆盖其文件，不使用其存储，不改变它的 Git 分支。

下载交付使用同一 GitHub 仓库下的独立试用分支 `visual-collector-trial`，拥有单独的提交历史。原 BOSS 项目的 `main` 分支保持不变。请把两个工具放在不同文件夹；不要让它们同时操作同一个网页。

## 默认使用简单模式

打开职位列表，点击工作台图标后，主要操作在最上方的“简单模式”卡片完成：

1. 填采集数量，点 **自动识别页面**。工具尝试识别列表、职位名称、薪资、公司、详情入口和下一页，并直接显示前5条预览。
2. 需要详情时保持“同时读取职位详情”勾选，再点 **自动读取详情**。工具自己打开一个职位试读，识别完整正文并保存规则。Chrome 请求这两个网站的访问权限时点“允许”。
3. 预览正确后点 **开始采集**，随后逐条读取、翻页、保存和导出 Excel。只需要列表信息，取消“同时读取职位详情”，可跳过第2步。

不能自动识别的地方只提示一次具体补充动作：列表或入口不明确时“点一个职位标题”；详情正文不明确时自动打开样例，再提示“点选职位描述”。详情试读期间可以“取消准备”。遇到登录/验证码会打开对应页面，请手动完成后回来重试。

识别成功的模板自动保存，配置草稿也会保留。字段、定位规则、模板导入导出与手动翻页配置都收进 **高级设置（可选）**。已保存的模板仍可选用，之后通常只需调整数量并开始。

自动识别支持常见招聘卡片、部分HTML表格和普通可见文字，不保证每个网站都能直接识别。找不到下一页时明确提示只采当前页；可以在高级设置补选翻页按钮。网站使用特殊字体显示薪资时会提示并跳过，避免导出错误数字。识别前若已有结果，需先导出并清空，不会自动删除旧数据。请先用3条核对预览与实际导出，再扩大数量。

0.2.1 修复未设置列表时点选标题后无法结束的问题：标题所属卡片具有重复结构时，自动识别列表并保存每条卡片内的点击位置；无法可靠识别时显示中文操作提示。空的、无效的或不匹配记录的列表规则会在点选前提示，不再显示浏览器的英文选择器错误。连接详情样例时会检查是否误选了列表标签页。

0.2.0 新增“进入详情页”模式：列表页和详情样例分别连接、分别点选；按顺序读取多个职位的详情后合并成一行，保留详情网址并导出 Excel。每个列表任务复用一个后台详情标签页，结束时自动关闭；不会关闭你手动打开的样例。配置草稿自动保存在本机，切换页面后可以继续配置。

## 已安装独立工作台：更新方式

关闭正在采集的任务，把新包中 **extension 文件夹里的文件**复制到你之前加载的独立工作台 extension 文件夹，选择覆盖。然后到 `chrome://extensions`，找到“网页采集工作台 · 独立试用版”，点卡片上的圆形重新加载按钮，确认版本 **0.3.0**。刷新职位列表和详情样例页，再点击工作台图标。不要覆盖 BOSS 职位导出扩展的文件。

如果不记得原来的独立工作台文件夹，可把新包放在一个固定位置，通过“加载未打包的扩展程序”选择新的 extension 文件夹，并停用旧的独立工作台。已有模板可先导出 JSON 再导入新版本。

## 高级设置：手动配置进入详情页（可选）

简单模式无法识别时，可以展开“高级设置”，按下面操作手动调整；之后同一个模板只需打开列表并点开始。

1. 在职位搜索列表打开工作台，点“连接列表页”。点选完整的职位卡片，配置职位名称、公司、薪资等列表字段；先预览，确认每行是不同职位。
2. 添加一个字段，名称填“职位描述”，读取区域改为“详情区字段”。下方“详情打开方式”选 **进入详情页（新标签页）**。
3. 手动打开一个职位详情。在该页点工作台工具栏图标，再点 **连接详情样例（当前标签页）**。回到“职位描述”卡片点“点选”，选择详情正文。可以按 ↑ 扩大到包含岗位职责、任职要求的完整正文；也可分别添加更多详情字段。
4. 点 **点选打开详情的位置**，工具会回到原列表，选择职位标题。不要选“投递”或“沟通”。如果标题有普通链接，也可新增一个列表字段，读取方式选“链接地址”，再在“使用哪一列作为详情链接”中选它。
5. 建议同时设置详情标识：点选详情页职位名称，并将列表标识设为“职位名称”。若名称显示不同可不设置；程序仍核对实际访问的网址。普通链接和由标题点击触发 `window.open(url)` 的入口均支持。
6. 设置翻页方式、目标条数和间隔，先预览。**添加详情字段后，旧的列表结果需先导出并清空**，再开始采集。初次启动时 Chrome 会请求访问所选的列表与详情网站，允许后才能自动读取。
7. 先试 3 条，核对 Excel 中三个不同职位的描述后，再增加目标数量继续。导出结果包含列表字段、详情字段、详情网址、来源页面与时间。

每个配置的详情字段都需有内容且稳定后才记录。若某些职位没有你选择的独立区块，会暂停；可将职责、要求选成一个完整正文，或删除不存在的字段后重新采集。遇到登录/验证码时，工作台保留此前结果并切到后台详情标签页，请手动完成后回到列表点“开始 / 继续”。暂停会取消当前详情读取；已成功采集的行不会丢失。

列表和详情可能是不同子域，例如 `we.51job.com` 与 `jobs.51job.com`，所以需要分别连接。预览仅显示当前样例的详情，不会将它复制给所有列表记录。新功能使用受控跨源测试网页验证，尚未在你登录的前程无忧会话中实测。

0.1.1 改进重复条目识别，支持每张卡片套一层独立包装的列表。新增“修复列表层级与字段”，可将误选的外层容器改为逐条记录，并把固定在第一条的字段重新定位到每条记录内部。预览会提示一个匹配项包含多个条目的可疑配置。翻页点到箭头图标时，会选择其按钮并检查禁用状态。

## 最快试玩：双击 HTML

解压后双击根目录的 **试玩.html**，无需安装任何东西。左边是明确标注的虚构演示数据，右边是可视化工作台。全部代码已包含在这个 HTML 文件里，断网也能用。

1. 点右侧“填入演示模板”。
2. 点“预览前5条”，检查字段。
3. 点“开始 / 继续”，自动采集12条并翻页、读取对应详情，导出真正的 `.xlsx`。
4. 也可以点“新建”，重新鼠标点选列表和字段，自由练习。切换“卡片列表 / 表格列表”能体验不同网页结构。

**离线演示只能采集自带的示例网页。要读取你浏览器里真实的网站，请安装独立扩展。**普通 HTML 无法直接控制其他网站的已登录页面。

## 安装到 Chrome，配置真实网页

1. 打开 `chrome://extensions`，开启开发者模式。
2. 点“加载未打包的扩展程序”，选择本项目的 **extension** 文件夹。不要覆盖、删除原来的 BOSS 扩展。
3. 打开需要采集的普通网页，点击新扩展“网页采集工作台”的工具栏图标。
4. 浏览器右侧打开工作台。建议先使用最上方“简单模式”；需要手动调整时展开“高级设置”。
5. 选择字段读取类型：文字、链接地址、图片地址。图片地址不等于图片内的文字。
6. 列表以外的字段选择“详情区”。先手动展开一条详情，再点选。配置列表的标识字段、详情中相同的标识、打开详情的位置及等待更新的字段。
7. 配置“只读当前列表 / 下一页 / 加载更多 / 滚动加载”、条数和间隔。
8. 预览前5条，确认字段和匹配数量，再运行。运行时不要手动改变网页列表或关闭目标标签页。

点选时按 **↑** 扩大到外层元素，按 **↓** 回到鼠标最初指向的元素，按 **Esc** 取消。鼠标移到另一个元素会更新高亮。

如果网页上有很多记录，工具却只匹配到1～2个大容器，或者字段定位中出现固定第一条的路径，请先点“修复列表层级与字段”。确认预览每行是不同记录。修改定位结构后，已有旧结果需先导出、清空，再运行。

## 模板和结果

- 保存模板：仅保存在本机，字段名称、定位规则、详情对应规则和翻页方式都能修改。
- 导入/导出 JSON 模板：不包含密码、Cookie 或采集结果，不会执行模板里的代码。
- 字段名需唯一。可勾选一个或多个列表字段用于去重；不选时优先使用配置的链接字段，否则使用整条记录文字。
- “详情预览”是当前打开详情的单独预览，不会把同一条详情伪装成多条列表的详情。
- Excel 自动删除全空列、保留来源和时间，超长文字分表保存；网站文字以普通文本写入，防止被当作 Excel 公式。
- 结果可暂停、继续、导出。可增加目标条数后继续采集，保留已有记录；减少条数时导出前 N 条。修改字段或定位结构后重新采集前，需要先导出并清空当前结果，避免混入不同结构。
- 扩展在同源的完整页面翻页后会尝试恢复；无法继续时保留此前结果。演示版是同页翻页。

## 试用边界

支持普通 DOM 中的列表、卡片、表格、同页详情、独立详情页及常见翻页。暂不支持依赖同一标签页跳转且无可读链接的入口、先打开空窗口再异步设置地址的入口、跨域 iframe、封闭 Shadow DOM、图片 OCR、网页特殊字体数字解码。定位规则过于宽泛、加载失败或详情无法对应时会停止并提示，不把错配的数据当作成功结果。

登录或安全验证需要你手动完成。点选使用 `activeTab`，在你主动点击工具栏图标后获得当前网页的临时权限；跨页采集启动时另行请求当前模板的两个具体网站权限，不会在安装时要求读取全部网站；不读取 Cookie、不调用隐藏业务接口、不上传模板或结果。第三方网站仍可能限制自动访问。

内置演示和真实 Chromium 功能测试验证的是通用引擎，不代表任意真实网站都无需调整。当前云环境管理员策略禁止加载未打包扩展及打开 file 页面，演示文件内容通过仅供内部测试的回环 HTTP 服务验证；本机双击打开、原生扩展安装/侧栏交接须在你的 Chrome 确认。

## 开发

```bash
python build.py
python -m unittest discover -s tests -v
node --test tests/test_bridge.mjs tests/test_details.mjs tests/test_panel.mjs
```

构建只需要 Python 标准库。测试额外使用 Playwright、openpyxl 和已安装的 Chromium。没有服务端，也不需要 API Key。
