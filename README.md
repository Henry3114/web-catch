# 前程无忧一键采集 1.0.0

这是独立的51job专用代码，不覆盖BOSS扩展，也不读取旧可视化工作台的模板。无需配置字段、定位规则或点选正文。

## 使用

1. 把本项目放到一个固定文件夹。在 Chrome 的 `chrome://extensions` 开启开发者模式，选择“加载未打包的扩展程序”，选择本项目的 **extension** 文件夹。扩展名称为“前程无忧一键采集”，版本1.0.0。原可视化工作台请停用，避免误点；原BOSS工具可保留。
2. 在 Chrome 登录51job，打开职位搜索列表。点击新扩展图标，填写搜索关键词和数量，再点“开始／继续”。首次需要允许列表站和详情站这两个51job网站的访问权限。
3. 工具使用正常职位点击所发出的链接，逐条打开后台详情、读取固定字段，自动翻页并保存进度。可以关闭这个小窗口；再次点图标查看进度。保持浏览器和职位列表标签页打开，采集中不要改变列表条件。
4. 达到目标数量后自动下载Excel；也可随时手动“导出Excel”。暂停、验证码或数量不足不会自动导出成已完成，手动导出文件名明确标出“未完成”和目标数量。
5. 需要换关键词或数量时，先导出已有结果，再点“新任务”。“开始／继续”用于继续同一批任务。

## 固定字段

职位名称、薪资待遇、公司名称、工作地点、工作职责、任职资格、公司性质、公司规模、行业、公司介绍。

同时保存原始职位描述、缺项提示、职位链接、来源和时间。职责/要求按已保存网页中的明确标题分开，缺少标题不把整篇正文重复写入两列；读取不到的字段留空并标注。正常缺项不终止循环，登录验证、职位对应错误或整个页面结构不支持时暂停保留结果。不会投递简历、发消息或读取Cookie，不调用隐藏业务接口。

## 验证范围

字段提取已在用户提供的列表HTML与两个真实详情HTML上验证。测试输入先移除脚本、外链和账号页面内容，仅使用职位卡片及公司/职位正文；用户上传的原始文件和提取结果不随此仓库公开。

后台另有浏览器API模拟测试：20条目标确实处理20条，个别缺项不中断；错误对应暂停；数量不足明确报告；只有达到目标才自动下载。这不等于已在用户的在线登录会话里跑过20条。云端浏览器管理员策略禁止加载未打包扩展，安装与在线跳转仍需在用户Chrome确认；首次建议采3条核对，然后开始20条新任务。

## 开发

无后端，无API Key，无运行时Python依赖。构建：`python build.py`。后台测试：`node --test tests/test_worker.mjs`。真实HTML测试：在保存了用户脱除脚本后的私有测试样例的环境中，使用Playwright运行 `python -m unittest discover -s tests -v`；无私有样例时跳过这些测试。
