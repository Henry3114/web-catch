# 网页采集工作台（独立试用版 0.1.1）

这是一个单独的新项目。它不引用 BOSS 专用扩展的运行环境，不覆盖其文件，不使用其存储，不改变它的 Git 分支。

下载交付使用同一 GitHub 仓库下的独立试用分支 `visual-collector-trial`，拥有单独的提交历史。原 BOSS 项目的 `main` 分支保持不变。请把两个工具放在不同文件夹；不要让它们同时操作同一个网页。

0.1.1 改进重复条目识别，支持每张卡片套一层独立包装的列表。新增“修复列表层级与字段”，可将误选的外层容器改为逐条记录，并把固定在第一条的字段重新定位到每条记录内部。预览会提示一个匹配项包含多个条目的可疑配置。翻页点到箭头图标时，会选择其按钮并检查禁用状态。

## 最快试玩：双击 HTML

解压后双击根目录的 **试玩.html**，无需安装任何东西。左边是明确标注的虚构演示数据，右边是可视化工作台。全部代码已包含在这个 HTML 文件里，断网也能用。

1. 点右侧“填入演示模板”。
2. 点“预览前5条”，检查字段。
3. 点“开始 / 继续”，自动采集12条并翻页、读取对应详情，导出真正的 `.xlsx`。
4. 也可以点“新建”，重新鼠标点选列表和字段，自由练习。切换“卡片列表 / 表格列表”能体验不同网页结构。

**离线演示只能采集自带的示例网页。要读取你浏览器里真实的网站，请安装独立扩展。**普通 HTML 无法直接控制其他网站的已登录页面。

## 安装到 Chrome，配置真实网页

1. 打开 `chrome://extensions`，开启开发者模式。
2. 点“加载未打包的扩展程序”，选择本项目的 **extension** 文件夹。不要覆盖、删除原来的 BOSS 扩展。
3. 打开需要采集的普通网页，点击新扩展“网页采集工作台”的工具栏图标。
4. 浏览器右侧打开配置工作台。先点选一条完整列表记录，再添加字段并点选文字位置。
5. 选择字段读取类型：文字、链接地址、图片地址。图片地址不等于图片内的文字。
6. 列表以外的字段选择“详情区”。先手动展开一条详情，再点选。配置列表的标识字段、详情中相同的标识、打开详情的位置及等待更新的字段。
7. 配置“只读当前列表 / 下一页 / 加载更多 / 滚动加载”、条数和间隔。
8. 预览前5条，确认字段和匹配数量，再运行。运行时不要手动改变网页列表或关闭目标标签页。

点选时按 **↑** 扩大到外层元素，按 **↓** 回到鼠标最初指向的元素，按 **Esc** 取消。鼠标移到另一个元素会更新高亮。

如果网页上有很多记录，工具却只匹配到1～2个大容器，或者字段定位中出现固定第一条的路径，请先点“修复列表层级与字段”。确认预览每行是不同记录。修改定位结构后，已有旧结果需先导出、清空，再运行。

## 模板和结果

- 保存模板：仅保存在本机，字段名称、定位规则、详情对应规则和翻页方式都能修改。
- 导入/导出 JSON 模板：不包含密码、Cookie 或采集结果，不会执行模板里的代码。
- 字段名需唯一。可勾选一个或多个列表字段用于去重；不选时优先使用配置的链接字段，否则使用整条记录文字。
- “详情预览”是当前打开详情的单独预览，不会把同一条详情伪装成多条列表的详情。
- Excel 自动删除全空列、保留来源和时间，超长文字分表保存；网站文字以普通文本写入，防止被当作 Excel 公式。
- 结果可暂停、继续、导出。可增加目标条数后继续采集，保留已有记录；减少条数时导出前 N 条。修改字段或定位结构后重新采集前，需要先导出并清空当前结果，避免混入不同结构。
- 扩展在同源的完整页面翻页后会尝试恢复；无法继续时保留此前结果。演示版是同页翻页。

## 试用边界

支持普通 DOM 中的列表、卡片、表格、同页详情及常见翻页。当前不支持新标签页详情、跨域 iframe、封闭 Shadow DOM、图片 OCR、网页特殊字体数字解码。定位规则过于宽泛、加载失败或详情无法对应时会停止并提示，不把错配的数据当作成功结果。

登录或安全验证需要你手动完成。新扩展使用 `activeTab`，仅在你主动点击工具栏图标后获得当前网页的临时权限；不读取 Cookie、不调用隐藏业务接口、不上传模板或结果。第三方网站仍可能限制自动访问。

内置演示和真实 Chromium 功能测试验证的是通用引擎，不代表任意真实网站都无需调整。当前云环境管理员策略禁止加载未打包扩展及打开 file 页面，演示文件内容通过仅供内部测试的回环 HTTP 服务验证；本机双击打开、原生扩展安装/侧栏交接须在你的 Chrome 确认。

## 开发

```bash
python build.py
python -m unittest discover -s tests -v
```

构建只需要 Python 标准库。测试额外使用 Playwright、openpyxl 和已安装的 Chromium。没有服务端，也不需要 API Key。
